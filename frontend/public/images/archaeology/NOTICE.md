# Pequeno Arqueólogo artifact photos — source and licensing

Real photographs of the actual kind of artifact each dig-site item
describes, sourced from Wikimedia Commons (commons.wikimedia.org),
license-verified per file, fetched via the Commons `imageinfo` API at a
fixed 500px width (server-side resized, no local recompression needed),
all well under 300KB.

Not every artifact has a photo yet — the rest fall back to their existing
emoji, which still renders fine on its own.
