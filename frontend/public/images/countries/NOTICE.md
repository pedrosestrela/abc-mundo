# Country photos — source and licensing

Each country in the World module can show a real "representative animal"
photo and a real "notable landmark" photo (`<iso>-animal.jpg` /
`<iso>-landmark.jpg`), matched to whatever `frontend/src/content/countries.json`
already names for that country's `animal.name` / `landmark` field. Full
per-country credit (author, license, source URL) is also recorded in
`frontend/src/content/countryPhotos.json` — this file exists as the
human-readable equivalent, alongside the audio NOTICE files.

All images below are sourced from [Wikimedia Commons](https://commons.wikimedia.org)
under a public-domain, CC0, or CC-BY / CC-BY-SA license — reduced in
size/quality for a fast-loading PWA (each file is well under 300KB), but not
otherwise altered in content. No image has been cropped in a way that
misrepresents the subject.

## Coverage

32 of 53 countries in `countries.json` currently have both an animal and a
landmark photo. The remaining ~21 countries fall back to no photo in
`CountryPhotoStrip` (see `frontend/src/pages/World.jsx`) — a future pass can
extend coverage the same way, following the exact sourcing/compression
method above.
