sourced from Wikimedia Commons (commons.wikimedia.org). All are
public-domain / CC0 / CC-BY / CC-BY-SA licensed, verified on each file's
own Commons File: page before download. Files were fetched via the Commons
`imageinfo` API at a fixed 500px width (server-side resized, no local
recompression needed) and are all well under 300KB.
