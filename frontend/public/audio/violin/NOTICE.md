# Violin samples — provenance & license

Source: `tonejs-instruments` sample library by Nicholas Brosowsky
(https://github.com/nbrosowsky/tonejs-instruments), distributed via the
MIT-licensed npm package `tonejs-instrument-violin-mp3`
(https://npm.im/tonejs-instrument-violin-mp3, published by Makefully
Studios — see https://github.com/Makefully-Studios/tonejs-instruments for
the packaging repo).

License:
- Code/packaging: MIT
- Audio samples: CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/) —
  per the package README: "Samples: CC-by 3.0". Original samples sourced
  from public-domain instrument recordings, edited (trimmed, normalized,
  pitch-corrected) by the tonejs-instruments project.

All 15 files shipped from the package (A3, A4, A5, A6, C4, C5, C6, C7, E4,
E5, E6, G3, G4, G5, G6). `music.js` pitch-shifts each sample via
`AudioBufferSourceNode.playbackRate` to cover the notes in between.

Note: these samples are used only for the "violin" instrument. The
separate "viola" instrument was NOT switched to sampled audio (no
separately-licensed viola sample pack was found) and remains synthesized.
